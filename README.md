# 📊 Sistema de Gestão de Notas de Turmas

Este é um trabalho desenvolvido no âmbito do curso da **Sharkcoders**! 🦈

O objetivo do programa é permitir o registo e a avaliação de alunos de uma turma da escola ou faculdade através do terminal.

## 🚀 Como funciona

1. O utilizador insere o **nome da turma** e a **quantidade de alunos**.
2. Em seguida, informa o **nome** e a **nota** de cada estudante.
3. Por fim, o sistema exibe o nome de cada aluno acompanhado da sua respetiva classificação:
   * Insuficiente
   * Suficiente
   * Bom
   * Muito Bom

## 📂 Versões do Projeto

O repositório conta com duas versões diferentes:
* **Versão 1 (Teste):** Uma versão inicial e mais simples, focada apenas na recolha básica de dados via `input`.
* **Versão 2 (Completa):** A versão principal e mais estruturada com todas as funcionalidades de avaliação 😊
